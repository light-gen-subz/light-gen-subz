Installation

Recommandé
curl -fsSL https://raw.githubusercontent.com/light-gen-subz/light-gen-subz/main/install.sh | bash
macOS → Homebrew Ubuntu / Debian → .deb Autres Linux → AppImage

Une seule commande pour les deux systèmes : elle détecte la plateforme et l’architecture. Sur macOS, Homebrew installe ffmpeg au passage ; sur Linux, ffmpeg doit être présent, avec glibc ≥ 2.38 (Ubuntu 24.04+, Debian 13+, Fedora 39+).

Ou manuellement

macOS
brew install --cask light-gen-subz/tap/light-gen-subz
Linux (.deb)
curl -fsSL -o light-gen-subz.deb "$(curl -fsSL https://api.github.com/repos/light-gen-subz/light-gen-subz/releases/latest | grep -o 'https://[^"]*_amd64\.deb' | head -1)" && sudo apt install ./light-gen-subz.deb
Linux (AppImage)
mkdir -p ~/.local/bin && curl -fsSL -o ~/.local/bin/light-gen-subz.AppImage "$(curl -fsSL https://api.github.com/repos/light-gen-subz/light-gen-subz/releases/latest | grep -o 'https://[^"]*_amd64\.AppImage' | head -1)" && chmod +x ~/.local/bin/light-gen-subz.AppImage

Désinstallation

Recommandé
curl -fsSL https://raw.githubusercontent.com/light-gen-subz/light-gen-subz/main/uninstall.sh | bash

Retire l’application quelle que soit la façon dont elle a été installée. Vos réglages et les modèles téléchargés sont conservés.

Ou manuellement

macOS
brew uninstall --cask light-gen-subz
Linux (.deb)
sudo apt remove light-gen-subz
Linux (AppImage)
rm ~/.local/bin/light-gen-subz.AppImage

Pour retirer aussi les modèles téléchargés et les réglages, voir le README.
